# Local demonstration data

All display names and scenarios are fictional. Import `employees.json` in Employees with the
upsert mode. Upload the three text files under Briefs and review extraction before confirming
them. The dates intentionally use weeks covered by the 2026 production calendar.

- `registry.txt` demonstrates a small Go API project.
- `dispatch.txt` overlaps a frontend specialist's vacation.
- `security.txt` requests a proficiency level above the demonstrated security profile.

Use a dedicated local demo database. Back it up and identify the previous demo records and their
dependencies before deleting them. The E2E fixtures belong to the test stack.
